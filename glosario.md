# Glosario de operaciones de farmacia

> **Documento ficticio para el workshop de Amazon Quick.** Los términos y criterios son de ejemplo.

| Término | Definición |
| --- | --- |
| **SKU** | Código único de un producto en una presentación específica (por ejemplo, ANA-001 = Paracetamol 500 mg x 20 tabletas). |
| **Local** | Punto de venta físico. Se identifica con un código: marca (FY = Fybeca, SS = SanaSana), ciudad y número, por ejemplo SS-GYE-01. |
| **Formato** | Tamaño del local: Grande, Mediano o Barrio. Determina el surtido y el stock mínimo. |
| **Stock mínimo** | Unidades que cubren cerca de 5 días de venta de un SKU en un local. Por debajo de este nivel se debe reponer. |
| **Quiebre de stock** | Un SKU cierra el día con stock en cero en un local. Se mide en días-SKU. |
| **Días-SKU en quiebre** | Suma de los días en que cada SKU estuvo en quiebre. Tres SKU en quiebre durante dos días suman 6 días-SKU. |
| **Venta perdida** | Venta que no ocurrió porque el producto no estaba disponible. |
| **Rotación** | Velocidad con que se vende el inventario de un SKU; alta rotación significa que se vende rápido. |
| **Reposición** | Envío de producto desde el centro de distribución al local para volver al nivel de stock deseado. |
| **Transferencia entre locales** | Traslado de producto de un local donante a otro local de la misma ciudad para evitar un quiebre (ver POL-OPS-003). |
| **Local donante** | Local con stock mayor a 2 veces su mínimo que puede ceder unidades. |
| **Cadena de frío** | Conjunto de controles que mantienen un producto refrigerado entre 2 °C y 8 °C (ver POL-OPS-002). |
| **Cuarentena** | Ubicación del sistema donde se bloquean productos que no se pueden vender hasta que Calidad los revise. |
| **Jefe zonal** | Responsable de un grupo de locales de una zona; aprueba transferencias. |
| **Temporada respiratoria** | Período en que sube la demanda de antigripales y productos para la garganta, más marcada en la Sierra. |
